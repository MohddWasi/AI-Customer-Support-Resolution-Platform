# Customer Communication Guidelines

Use clear and professional language.

For a known issue:
- State the issue.
- Explain the documented cause if known.
- Provide the documented resolution.
- Cite the relevant source.

For an uncertain issue:
- State what was checked.
- Explain what is still unknown.
- Ask only for information needed to continue.
- Escalate when evidence is insufficient.

Do not claim that an action was completed unless the corresponding tool returned a successful result.
